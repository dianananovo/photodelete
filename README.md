# 🌸 咻咻相册 (XiuXiu Photo Clean)

> **相册乱序清理应用-咻咻相册**

---

## 🎨 视觉风格：粉蓝 Ins 风 (Pastel Pink & Baby Blue)
- **初恋粉 (Pastel Pink #FF7597)**：上滑删除动态光晕、待确认池小徽标、确认清理渐变按钮。
- **治愈蓝 (Baby Blue #6BA3F5)**：下滑保留动态光晕、相册标题高亮、次级操作高光。
- **奶油白底 (Cream White #FAF9FD)**：透气明亮的留白背景，大圆角拍立得质感卡片。

---

## 🚀 核心功能与操作方式
1. **随机乱序推送**：
   - 自动扫描手机相册所有照片，并进行真正的洗牌乱序，确保利用零碎时间打开时，每次都能看到新鲜的旧照与回忆。
2. **直觉手势滑动**：
   - **上滑 (Swipe Up)**：将照片推出屏幕，标记为“移入待确认池”（伴随粉红色删除标签动效）。
   - **下滑 (Swipe Down)**：将照片沉入底部，标记为“保留”（照片位置不变，伴随蓝色保留标签动效）。
   - **底部快捷按键**：即使单手操作不便滑屏，也可直接点击底部的“保留 💖”、“撤销 ↩️”、“删除 🗑️”大圆钮。
   - **一键撤销 (Undo)**：手滑误判随时可一键回退到上一张。
3. **待确认池二次审核**：
   - 随时点击右上角“待确认池(X)”胶囊按钮结束当次清理。
   - 3 列自适应缩略图瀑布流，清晰展示所有被标记删除的照片。
   - **点击大图查看**：点击缩略图即可弹出全屏高清大图，细致对比拍摄时间、分辨率与细节，绝不误删珍贵照片。
   - **灵活勾选**：默认全选，可单张取消勾选（取消的照片恢复保留）。
4. **系统原生安全删除（一加15 适配）**：
   - 调用 Android 11~15 原生 MediaStore.createTrashRequest。
   - 点击“确认清理”后，触发一加手机系统安全批量确认对话框（*默认移入一加相册“最近删除”回收站，30天内可随时在系统相册恢复，最安全防呆*）。
   - 删除成功后，弹出可爱的结算弹窗，清晰反馈本次释放了多少 MB 空间。
