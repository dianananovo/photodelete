## 🚀 核心功能与操作方式

1. **随机乱序推送**：
   - 自动扫描手机相册所有照片，并进行真正的洗牌乱序，确保利用零碎时间打开时，每次都能看到新鲜的旧照与回忆。
2. **直觉手势流**：
   - **上滑 (Swipe Up)**：将照片推出屏幕，标记为“移入待确认池”（伴随粉红色删除标签动效）。
   - **下滑 (Swipe Down)**：将照片沉入底部，标记为“保留”（照片位置不变，伴随蓝色保留标签动效）。
   - **底部快捷按键**：即使单手操作不便滑屏，也可直接点击底部的“保留 💖”、“撤销 ↩️”、“删除 🗑️”大圆钮。
   - **一键撤销 (Undo)**：手滑误判随时可一键回退到上一张。
3. **待确认池二次审核**：
   - 随时点击右上角“待确认池 (X)”胶囊按钮结束当次清理。
   - 3 列自适应缩略图瀑布流，清晰展示所有被标记删除的照片。
   - **点击大图查看**：点击缩略图即可弹出全屏高清大图，细致对比拍摄时间、分辨率与细节，绝不误删珍贵照片。
   - **灵活勾选**：默认全选，可单张取消勾选（取消的照片恢复保留）。
4. **系统原生安全删除（一加15 适配）**：
   - 调用 Android 11~15 原生 `MediaStore.createTrashRequest`。
   - 点击“确认清理”后，触发一加手机系统安全批量确认对话框，**默认移入一加相册“最近删除/回收站”**（30天内可随时在系统相册恢复，最安全防呆）。
   - 删除成功后，弹出可爱的结算弹窗，清晰反馈本次释放了多少 MB 空间。

## 🖥️ 快速体验与真机运行

### 方式一：在电脑浏览器立即体验（无需安装任何环境）
在当前工程根目录下，直接**双击打开 `preview_demo.html`**，即可在浏览器中体验完整的高保真粉蓝 ins 风交互效果，包含上滑删除、下滑保留、撤销、待确认池网格多选和大图预览！

### 方式二：安装到一加15真机（Android Studio）
1. 下载并安装 [Android Studio](https://developer.android.com/studio)；
2. 打开 Android Studio，选择 **Open**，选中本目录 `f:\photodelete`；
3. 一加15 手机开启开发者模式：
   - 打开手机【设置】->【关于本机】->【版本信息】-> 连续点击【版本号】7次，开启开发者模式；
   - 返回【设置】->【系统与更新】/【其他设置】->【开发者选项】-> 打开【USB 调试】；
4. 用数据线将一加15连接电脑，在手机弹出的授权框勾选“一律允许这台电脑进行调试”；
5. 在 Android Studio 右上角的设备列表选中您的一加15手机，点击绿色的 **Run (运行)** 按钮，即可自动打包并安装运行！
